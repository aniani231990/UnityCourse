## 📚 Как работает обучение

Каждая тема проходит **4 фазы**:

### 1. ТЕОРИЯ (30-45 мин)
- ИИ объясняет **по частям** (не все сразу!)
- После каждой части: СТОП → вопрос → ждет ответ
- Проблема → Концепция → Пример → Trade-offs

### 2. ПРАКТИКА (60-90 мин)
- 🟢 Задача 1 (легкая) → решаете → проверка
- 🟡 Задача 2 (средняя) → решаете → проверка
- 🔴 Задача 3 (сложная, optional)
- **ПО ОДНОЙ!** Не все сразу.

### 3. ПРОВЕРКА ПОНИМАНИЯ (20 мин)
- Вопросы на разных уровнях
- От простых к сложным
- 80%+ правильно → переходим дальше

### 4. ЗАКРЕПЛЕНИЕ (15 мин)
- **Feynman Technique**: вы объясняете ИИ
- ИИ задает вопросы "новичка"
- Проверка глубины понимания

## ⚠️ Частые проблемы и решения

### ❌ Проблема: ИИ выдает огромную простыню текста

**Решение:**
```
СТОП! Следуй инструкции V2!

НЕ давай всю теорию сразу. Давай по частям:
1. Проблема → СТОП → жди ответ
2. Концепция → СТОП → жди ответ

Начни заново. Только ПРОБЛЕМА.
```

### ❌ Проблема: ИИ дает все 3 задачи сразу

**Решение:**
```
СТОП! ТОЛЬКО Задача 1.

ЖДИ пока я решу → проверь → вопросы → ПОТОМ Задача 2.
```

### ❌ Проблема: ИИ дает готовый код

**Решение:**
```
СТОП! Не давай код!

Направляй ВОПРОСАМИ:
- Какая структура данных?
- Как будешь искать?
- Что если null?

Я пишу код. Ты задаешь вопросы.
```

## 📋 Важные правила

### ✅ ЧТО ДЕЛАТЬ:
- Писать код **самостоятельно**
- Задавать вопросы если непонятно
- Отвечать на вопросы ИИ честно
- Объяснять концепции обратно

### ❌ ЧЕГО НЕ ДЕЛАТЬ:
- НЕ просить готовый код
- НЕ говорить "понял" если не поняли
- НЕ пропускать проверку понимания
- НЕ спешить к следующей теме

## ❓ FAQ

**Q: Инструкция на английском - ИИ будет отвечать по-английски?**
A: Нет! В инструкции явно указано: "Respond to student ONLY in RUSSIAN". ИИ понимает английские команды лучше, но всегда отвечает на русском.

**Q: ИИ выдает всю теорию сразу. Что делать?**
A: Используйте команду из [CHEAT-SHEET.md](CHEAT-SHEET.md) → "ИИ выдает всю теорию сразу"

**Q: ИИ не спрашивает "понятно ли"?**
A: Напомните: `Следуй каждому "STOP ⛔ WAIT FOR ANSWER" строго!`

**Q: Нужно ли отправлять инструкцию каждую сессию?**
A: Да! ИИ не помнит прошлые разговоры.

**Q: Что если застрял на задаче?**
A: `Застрял. Помоги декомпозировать на подзадачи.`

**Q: Как узнать, готов ли к следующей теме?**
A: ИИ проверит через вопросы. Если 80%+ правильно → готовы.
