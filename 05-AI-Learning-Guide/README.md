## 🎓 Структура каждой учебной сессии

Каждая тема проходит через **4 фазы**:

### Фаза 1: ТЕОРИЯ (30-45 мин)
- ИИ объясняет концепцию
- Показывает проблему → решение
- Приводит примеры (простой → сложный)
- Обсуждает trade-offs
- Проверяет понимание вопросами

### Фаза 2: ПРАКТИКА (60-90 мин)
- 🟢 Легкая задача (разогрев)
- 🟡 Средняя задача (основная)
- 🔴 Сложная задача (challenge)
- ИИ проверяет ваш код
- Задает вопросы на понимание
- НЕ дает готовое решение!

### Фаза 3: ПРОВЕРКА ПОНИМАНИЯ (20 мин)
- Вопросы на разных уровнях (от простых к сложным)
- Remember → Understand → Apply → Analyze → Evaluate → Create
- ИИ проверяет глубину понимания
- Находит пробелы в знаниях

### Фаза 4: ЗАКРЕПЛЕНИЕ (15 мин)
- Feynman Technique: вы объясняете тему ИИ
- Code Review Challenge: найти ошибки в чужом коде
- Real-World Connection: связь с реальными проектами

## 📋 Важные правила

### ✅ ЧТО ДЕЛАТЬ:
- Писать код САМОСТОЯТЕЛЬНО
- Задавать вопросы, если непонятно
- Отвечать на вопросы ИИ честно
- Объяснять концепции обратно
- Практиковать 80% времени

### ❌ ЧЕГО НЕ ДЕЛАТЬ:
- НЕ просите готовый код
- НЕ говорите "понял", если не поняли
- НЕ копируйте код без понимания
- НЕ пропускайте проверку понимания
- НЕ спешите к следующей теме

## ❓ FAQ

**Q: Нужно ли читать инструкцию ИИ каждую сессию?**
A: Да! В начале каждой сессии напоминайте ИИ о инструкции или отправляйте ее снова.

**Q: Что если ИИ дает готовый код сразу?**
A: Напомните: "Следуй AI-MENTOR-INSTRUCTION.md. Не давай готовый код, задавай вопросы."

**Q: Можно ли пропустить теорию?**
A: Попросите ИИ дать quick check (3 вопроса). Если ответите правильно - можно к практике.

**Q: Что делать, если застрял?**
A: Скажите ИИ: "Застрял. Помоги декомпозировать задачу на подзадачи."

**Q: Как узнать, готов ли я к следующей теме?**
A: ИИ проверит через вопросы. Если 80%+ правильных ответов - готовы.
