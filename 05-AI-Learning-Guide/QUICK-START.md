# Quick Start: Работа с ИИ-наставником

## 🚀 Быстрый старт за 5 минут

### Шаг 1: Загрузите инструкцию ИИ

**Скопируйте весь файл** [AI-MENTOR-INSTRUCTION.md](AI-MENTOR-INSTRUCTION.md) и отправьте его вашему ИИ (Qwen, Claude, GPT) в начале сессии.

Или используйте короткий промпт:
```
"Прочитай файл AI-MENTOR-INSTRUCTION.md из папки 05-AI-Learning-Guide.

Ты будешь моим ментором по Unity + C# + Architecture.

Твоя задача:
1. Объяснять теорию пошагово
2. Давать задачи и проверять мои решения
3. Задавать вопросы на понимание
4. НЕ давать готовый код сразу

Следуй инструкции строго.

Начнем с [Название темы, например: Module 01: Delegates]"
```

### Шаг 2: Начните с теории

ИИ начнет объяснять тему. **Ваша задача:**
- Слушайте внимательно
- Задавайте вопросы, если непонятно
- Отвечайте на вопросы ИИ
- Просите примеры

### Шаг 3: Практика

ИИ даст вам задачу. **Ваша задача:**
- Писать код САМОСТОЯТЕЛЬНО
- Показывать ИИ для проверки
- Отвечать на вопросы ИИ о вашем коде
- Улучшать код на основе feedback

### Шаг 4: Проверка понимания

ИИ задаст вопросы. **Ваша задача:**
- Отвечать честно
- Если не знаете - говорите "Не знаю"
- Просите объяснить еще раз, если нужно

### Шаг 5: Объяснение обратно

ИИ попросит объяснить тему. **Ваша задача:**
- Объяснить своими словами
- Как будто объясняете другу
- Без сложных терминов

## 📋 Готовые промпты для начала

### Начало нового модуля (C#)

```
"Начинаем Module [NN]: [Название темы]

Следуй инструкции AI-MENTOR-INSTRUCTION.md:
1. Объясни теорию (проблема → решение → примеры)
2. Дай 3 задачи (легкая, средняя, сложная)
3. Проверь понимание (вопросы на разных уровнях)
4. Попроси меня объяснить обратно (Feynman Technique)

Я готов. Начинай с теории!"
```

### Начало нового паттерна (Architecture)

```
"Начинаем изучение [Название паттерна]

Следуй инструкции AI-MENTOR-INSTRUCTION.md:
1. Объясни проблему, которую решает паттерн
2. Покажи примеры (BAD vs GOOD code)
3. Дай практические задачи
4. Проверь глубину понимания

Начинай!"
```

### Практика без теории (если уже знаю тему)

```
"Хочу попрактиковать [Тема]

Не нужна теория, сразу к задачам:
1. Дай мне 3 задачи (легкая → средняя → сложная)
2. Проверяй мой код
3. Задавай вопросы на понимание
4. Указывай на ошибки, но НЕ давай готовое решение

Начинай с задачи 1!"
```

### Code Review моего кода

```
"Сделай code review моего [Название проекта/класса]

Проверь:
1. Правильность применения паттернов
2. SOLID принципы
3. Clean Code (naming, structure)
4. Edge cases
5. Performance

Вот код:
[вставить код]

Укажи:
- ✅ Что хорошо (и почему)
- ⚠️ Что можно улучшить (и как)
- ❌ Что плохо (и почему)

Следуй инструкции AI-MENTOR-INSTRUCTION.md"
```

### Debugging помощь

```
"Помоги отладить проблему:

Проблема: [описание бага]
Код: [код]
Что я пробовал: [ваши попытки]
Моя гипотеза: [что вы думаете]

НЕ давай готовое решение!
Задавай вопросы, помоги найти проблему самому.

Следуй инструкции AI-MENTOR-INSTRUCTION.md"
```

## ⚡ Полезные команды во время обучения

### Если непонятно:
```
"Не понял эту часть. Объясни проще / покажи пример / используй аналогию"
```

### Если застрял:
```
"Застрял на [конкретном месте]. Дай подсказку (но не решение!)"
```

### Если нужна декомпозиция:
```
"Задача сложная. Помоги разбить на подзадачи"
```

### Если хочу проверить решение:
```
"Готов! Вот мой код. Проверь и задай вопросы на понимание"
```

### Если хочу челлендж:
```
"Слишком легко! Дай более сложную задачу"
```

### Если нужно повторить:
```
"Хочу повторить [тему]. Задай мне вопросы для проверки"
```

## 🎯 Правила эффективного обучения

### ✅ ДО:
- Читайте инструкцию ИИ в начале КАЖДОЙ сессии
- Пишите код самостоятельно
- Задавайте вопросы, если непонятно
- Объясняйте концепции обратно
- Практикуйте 80% времени

### ❌ НЕ ДО:
- Не копируйте готовый код от ИИ
- Не говорите "понял", если не поняли
- Не пропускайте проверку понимания
- Не просите ИИ решить за вас
- Не спешите к следующей теме

## 📅 Ежедневный план (2 часа)

### День обучения:

**30 мин** - Теория
- ИИ объясняет концепцию
- Вы задаете вопросы
- ИИ проверяет понимание

**60 мин** - Практика
- Решаете задачи
- Показываете код ИИ
- Улучшаете на основе feedback

**20 мин** - Проверка
- ИИ задает вопросы
- Вы отвечаете
- ИИ указывает на пробелы

**10 мин** - Закрепление
- Объясняете тему ИИ
- ИИ проверяет глубину понимания

## 🔄 Цикл обучения

```
Новая тема
    ↓
Теория (ИИ объясняет)
    ↓
Практика (Вы пишете код)
    ↓
Feedback (ИИ проверяет)
    ↓
Вопросы (ИИ проверяет понимание)
    ↓
Объяснение обратно (Вы объясняете ИИ)
    ↓
Закреплено ✅
    ↓
Следующая тема
```

## 💡 Примеры хороших вопросов ИИ

### Для теории:
- "Объясни через аналогию из реального мира"
- "Покажи примеры из известных игр"
- "Сравни X и Y: когда что использовать?"

### Для практики:
- "Дай задачу, которая заставит понять [концепцию] на практике"
- "Проверь мой код и задай вопросы на понимание"
- "Какие edge cases я не учел?"

### Для углубления:
- "Как это работает под капотом?"
- "Какие продвинутые техники существуют?"
- "Как профи используют это?"

---

## 🎓 Что делать после завершения темы

1. **Отметьте прогресс**
   - ИИ оценит ваш уровень по теме

2. **Сделайте перерыв**
   - 10-15 минут отдыха

3. **Повторите через время**
   - День 1, День 3, День 7

4. **Примените в проекте**
   - Используйте в своей игре
