# Unity Learning Path with AI Assistant

Персональный учебный репозиторий для освоения Unity + C# + Architecture на уровне Middle/Senior.

## Входные данные студента

- ✅ Python опыт (Data Analysis)
- ✅ Unity basics (курсы от Unity, CodeMonkey)
- ✅ Практика: FlappyBird, Snake
- ✅ Теория: SOLID, паттерны (ObjectPool, EventBus)
- 🎯 **Цель:** Middle/Senior Unity Developer за 12-24 месяца

## Методология обучения

**AI-Assisted Learning** - работа с AI-ассистентом (Qwen/Claude):
- AI рассказывает теорию с примерами
- AI дает задачки с пошаговой проверкой
- AI задает вопросы на понимание
- AI делает code review ваших решений
- AI объясняет ошибки и показывает лучшие практики

## Принципы обучения

- 🎯 **Практика > Теория** (80/20)
- 🎯 **Build, don't follow** (создавайте, не копируйте)
- 🎯 **Explain to learn** (объясняйте AI то, что поняли)
- 🎯 **Daily consistency** (2 часа каждый день)
- 🎯 **AI as mentor** (не как Google, а как наставник)
