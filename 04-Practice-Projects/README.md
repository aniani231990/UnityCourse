# Practice Projects

Эта папка для ваших учебных проектов.

## Структура

Каждый проект в отдельной папке:
```
04-Practice-Projects/
├── 01-EventBus-System/
├── 02-ObjectPool-BulletHell/
├── 03-StateMachine-BossAI/
├── 04-CardGame-Immutable/
└── ...
```

## Как работать с проектами

1. **Создайте новую папку** для каждого проекта
2. **README.md** в каждой папке:
   - Цель проекта
   - Что изучается (паттерны, техники)
   - Требования
   - Как запустить

3. **Commit после каждого milestone**
   ```bash
   git add 04-Practice-Projects/01-EventBus-System/
   git commit -m "feat: complete EventBus basic implementation"
   ```

4. **Code Review от AI** после завершения
   - Попросите Qwen сделать code review
   - Добавьте feedback в REVIEW.md
